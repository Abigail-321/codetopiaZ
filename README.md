# CodeTopiaZ 🚀

CodeTopiaZ is an interactive web development learning platform designed to make coding accessible, hands-on, and engaging through instant feedback and gamified progression.

🌐 **Live Demo:** [codetopiaz.vercel.app](https://codetopiaz.vercel.app)

---

## ✨ Features

- **Interactive Code Workspace:** Practice HTML, CSS, and JavaScript with live browser rendering.
- **Automated Validation:** Instant feedback on challenge submissions using custom validation rules.
- **Structured Curriculum:** Progressive tracks taking learners from foundational layouts to dynamic DOM logic.
- **Pixel Mentor "Byte":** Gamified guidance throughout the learning journey.
- **Secure Authentication:** User session management powered by Clerk.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Lucide Icons
- **Database & ORM:** PostgreSQL, Prisma ORM
- **Authentication:** Clerk Auth
- **Deployment:** Vercel
